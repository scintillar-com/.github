# Getting help

Scintillar tools are free and shared as-is. There's no paid support, no SLA and no guaranteed response time: help is best-effort, from the community, on GitHub.

- **Questions and problems:** open an issue in the tool's repository. Say which version you run and how you deployed it.
- **Bugs and feature ideas:** use the issue templates in the tool's repository.
- **Security issues:** don't open a public issue. Follow [SECURITY.md](SECURITY.md).

Before you open an issue, check the tool's documentation and search existing issues: your answer may already be there.

The tools are meant for hobbyists and small projects. If you run something business-critical, plan for the case where nobody is available to help.
