# .github

Default community files for every repository in the [Scintillar](https://scintillar.com) organization.

Scintillar is a digital playground of free, open-source, white-label tools that people host and run under their own brand. GitHub applies the files below to any `scintillar-com` repository that doesn't have its own version:

| File | What it covers |
| --- | --- |
| [CONTRIBUTING.md](CONTRIBUTING.md) | How to report issues and open pull requests |
| [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) | How we expect people to treat each other |
| [SECURITY.md](SECURITY.md) | How to report a vulnerability privately |
| [SUPPORT.md](SUPPORT.md) | Where to get help, and what to expect |
| [ISSUE_TEMPLATE/](ISSUE_TEMPLATE) | Bug report, feature request and chore templates |

A repository can override any of them by adding its own copy.

## Labels

[labels.yml](labels.yml) lists the standard labels the issue templates use. Set them as the organization's default labels so new repositories start with them.
